# Project Tracking System

A Python-based Project Tracking System developed as part of my first-semester Programming Fundamentals coursework.

## 📌 Overview

The Project Tracking System is an interactive project management application built using Python and Google Colab.

It provides a dashboard and separate modules for managing projects, team members, tasks, bugs, milestones, reports, and project searches.

## ✨ Features

- 📊 Interactive project dashboard
- 📁 Project management
- 👥 Team member management
- ✅ Task management
- 🐛 Bug tracking
- 🎯 Milestone tracking
- 📈 Project reports
- 🔎 Project search
- 💾 In-memory data management
- 🖥️ Interactive interface using IPyWidgets
- 📋 Tables and data display using Pandas

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- IPyWidgets
- IPython HTML display

## 📚 Main Modules

### Dashboard

Displays an overview of projects, team members, tasks, bugs, and project progress.

### Projects

Allows projects to be added and project progress to be updated.

### Team Members

Stores information about team members, including their roles, departments, and skills.

### Tasks

Allows tasks to be assigned to team members and their status to be updated.

### Bug Tracker

Allows bugs to be reported, assigned, and resolved.

### Milestones

Allows project milestones to be created and marked as completed.

### Reports

Provides summaries of task statuses, bug severity, project counts, and budgets.

### Search

Allows projects to be searched by project name, client, or manager.
